# ADR-001：编辑器采用 ArkWeb + CodeMirror 6

- 状态：建议接受，M0-03 后确认。
- 背景：需要稳定输入法（中文组合输入）、选区、撤销重做、语法高亮与扩展生态；纯 ArkTS 自研文本编辑器首版成本与输入稳定性风险过高。
- 决策：编辑运行时承载于 ArkWeb，使用 CodeMirror 6；原生层通过版本化 JSBridge 发送低频命令与按需快照（SDD 8.4）。
- 后果：需要严格的桥接协议、Web 安全策略与资源本地打包；正文主副本位于 CodeMirror 文档模型，禁止逐键传输全文。
- 关联：FR-EDIT-001；M0-03 / M2-01 / M2-02。
