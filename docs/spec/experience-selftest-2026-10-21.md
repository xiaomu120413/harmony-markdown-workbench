# 木笺应用体验自测报告

2026-10-22 更新 · 版本 1.0.0 · API 24 · ST-QUALITY-001 / ST-QUALITY-002

## 结论与审核信息

已完成本报告列出的 PC 真机及 API 24 手机模拟器检查，11 组宿主自动化回归全部通过。本次补齐系统主题跟随、可聚焦的文档行及大纲、查找焦点与 Escape 返回，完成系统分屏比例调节。原有窗口、保存与导出结果保留为 10 月 21 日记录，本次主题、快捷键、保存、重开和菜单补验见下文。

本报告用于 L1/L2 送测前自查，不是华为认证报告。当前官方公开 UX 页面使用“必须、强烈推荐、推荐”标记，未取得当前申请入口的 L1/L2 原始检测清单和等级对照，不能给出 L1 或 L2 全项通过结论。宿主机测试也不等同于官方体验等级检测。

上一轮的系统主题和分屏比例缺口已关闭。PC 主路径的 Tab/Shift+Tab、Enter/Space、编辑快捷键及系统菜单已补验；未穷举全部文件选择器、附件授权与异常弹层的键盘路径。实体触控板、外接键盘插拔、系统字体放大、功耗/帧率/长稳及平台云测仍未完成。

### 可填写的审核备注

木笺为离线 Markdown 编辑器，无需注册登录，无广告、内购或付费入口。打开后可新建文档，输入正文后保存，并切换预览；也可通过系统文件选择器打开外部文件。PC 支持编辑与预览分屏、右键菜单及常用编辑快捷键。文件持久授权仅用于用户选定文件，授权不可用时会提示重新选择。本次附 PC 真机与 API 24 手机模拟器自测记录，未覆盖项目已注明。

“需要登录进行审核”：不勾选；无需提供测试账号。自测附件：mumark-1.0.0-api24-experience-selftest.docx。自测记录不能替代应用市场审核结论。
