2026-10-22 更新 · 版本 1.0.0 · API 24 · ST-QUALITY-001 / 002 / 003

## 结论与审核信息

已完成本报告列出的 PC 真机及 API 24 手机模拟器检查，11 组宿主回归及 SDK 本地单测 205/205 通过。本次再补齐手机横屏，修复入口旋转策略、横屏工具栏被隐藏及查找面板占满可用高度的问题。系统主题、PC 键盘与分屏比例保留本日已验证记录，原有窗口和 HTML 导出结果为 10 月 21 日记录。

本报告用于 L1/L2 送测前自查，不是华为认证报告。当前官方公开 UX 页面使用“必须、强烈推荐、推荐”标记，未取得当前申请入口的 L1/L2 原始检测清单和等级对照，不能给出 L1 或 L2 全项通过结论。宿主机测试也不等同于官方体验等级检测。

上一轮的系统主题和分屏比例缺口已关闭。PC 主路径的 Tab/Shift+Tab、Enter/Space、编辑快捷键及系统菜单已补验；未穷举全部文件选择器、附件授权与异常弹层的键盘路径。实体触控板、外接键盘插拔、系统字体放大、功耗/帧率/长稳及平台云测仍未完成。

### 可填写的审核备注

木笺为离线 Markdown 编辑器，无需注册登录，无广告、内购或付费入口。打开后可新建文档，输入正文后保存，并切换预览；也可通过系统文件选择器打开外部文件。PC 支持编辑与预览分屏、右键菜单及常用编辑快捷键。文件持久授权仅用于用户选定文件，授权不可用时会提示重新选择。本次附 PC 真机与 API 24 手机模拟器自测记录，未覆盖项目已注明。

## 手机横屏和 SDK 单测补验

Emulator 26.0.0.400 的官方 -instance "Pura 90" -rotation left/right 命令可以模拟传感器方向。入口原先未声明 orientation，手机默认策略保持竖屏；现设为 auto_rotation_restricted，实际窗口从 1320×2856 变为 2856×1320，两个横屏方向均测到，并验证系统旋转锁定开启时保持竖屏。

横屏无软键盘时保留工具栏，可预览并打开标题/格式/段落/插入菜单，长菜单可滚动；软键盘弹出后收起工具栏，编辑区实测高 319px。查找面板限高后，键盘场景编辑区仍有 81px，输入“保存”显示 1/2 命中。Escape 关闭查找、系统返回收键盘后工具栏与正文恢复。中文输入“横屏保存回归。”保存后取回 110 字节文件；撤销并保存还原到 89 字节，哈希与本报告原始样本相同。旋转过程中正文、查找选区和保存状态未丢失，最后保留竖屏并启用旋转锁定。

SDK 排查先发现依赖空目录，再遇旧缓存 scopeNames 冲突；重新安装依赖并备份移走 entry/.test 后，重新编译执行得到 205/205 通过。行覆盖率 81.02%（824/1017），函数 70.75%（104/147），分支 76.71%（280/365），仅指本轮 SDK 所统计模块，不代表整款应用覆盖率。

此前将 LocalSocket 日志直接写成 SDK 单测阻断不准确，本次已纠正：当前 SDK coverage 插件固定传入 IDE 命令/trace 管道名，纯 CLI 没有对应管道，Previewer 输出 CreateFileW 2、WriteFile 6；引擎仍完成测试并生成逐例结果与覆盖率。SDK 原始诊断尚未消失，没有修改 SDK、伪造管道或删除日志。新增门禁以本次时间戳、编译成功、205 条逐例结果、完成摘要和覆盖率综合判断；已验证失败用例、缺失摘要、零用例、过期结果及编译失败均被拒绝。CI 和本地 clean-build 已接入，不能仅凭 BUILD SUCCESSFUL 放行。
