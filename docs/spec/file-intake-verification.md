## 边界

- 当前真机为 API 26 的 2in1。未覆盖其他系统版本、手机/平板、所有云/网络文件提供方、跨设备拖入、超大文件与真实磁盘耗尽；Web.enableDrag 接口在当前 SDK 标注 26，旧系统需另做兼容验收。
- 自动化覆盖超时取消逻辑；未人为中断真实系统传输验证取消完成时序，取消失败会留日志，界面解除等待且不打开迟到结果。
- 拖入仅导入 UTF-8 文本副本，不导入兄弟图片目录；已有原文件编辑仍使用打开方式/选择器。网络图片及附件边界沿用前轮说明。
- 验收使用原签名不匹配情况下的独立验证包，未卸载原正式应用。正式覆盖升级仍需匹配的原签名。
- 屏幕阅读器、完整键盘焦点顺序、全尺寸/全设备布局未验证；已有 SDK 弃用与 ESObject 警告未在本任务中全面清理。
