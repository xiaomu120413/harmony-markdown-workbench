# 产品规格（稳定版）

> 源文档：`HarmonyMarkdownWorkbench-SDD.md` v1.0.0。本文件提取稳定需求供开发引用；与 SDD 冲突时以 SDD 为准，并在 ADR 中记录。
> 版本约定：MUST / SHOULD / MAY。

## 1. 定位

面向开发者、技术写作者和本地文档用户的鸿蒙原生 Markdown 文件工作台：无需账号，以标准 Markdown 文件为唯一真源，手机快速编辑、平板分屏预览，PC/2in1 预留工作区。

## 2. 范围（V0.1 MVP）

MUST：应用内资料库；新建/重命名/删除资料库文档；系统文件选择器打开 `.md/.markdown/.txt`；外部文件原位保存；编辑/预览/平板分屏；GFM 基础渲染（标题、列表、任务列表、表格、引用、链接、图片、代码块、删除线）；自动保存与保存状态；崩溃草稿恢复；外部修改冲突检测；最近/固定文件；大纲；查找替换；分享与"用其他应用打开"；深浅色主题；手机/平板响应式；物理键盘快捷键。

排除：AI 写作、账号与服务端、双链/知识图谱、插件市场、多人协作、WYSIWYG、任务提醒。

## 3. 成功指标（节选）

| 指标 | 目标 |
|---|---:|
| 冷启动至可输入（中端设备） | P95 ≤ 1.5 s |
| 正常编辑会话数据丢失率 | 0 |
| 崩溃草稿恢复成功率 | ≥ 99% |
| 1 MB Markdown 首次预览 | P95 ≤ 800 ms |
| 输入响应 | P95 ≤ 50 ms |
| 外部冲突静默覆盖 | 0 次 |

指标采集不得上传正文、路径、文件名或用户输入。

## 5. 关键原则（违反即视为缺陷）

1. 打开的是原文件，保存后仍是原文件（ADR-002）。
2. 元数据数据库不保存正文唯一副本（FR-FILE-001）。
3. 冲突时停止写入，用户决策优先，禁止默认覆盖（FR-FILE-004）。
4. 默认离线；V0.1 不申请 INTERNET 权限（6.3）。
5. 正文主副本位于 CodeMirror 文档模型，禁止逐键跨桥传输全文（M2-02 / 7.3）。
6. Markdown HTML 必须白名单过滤，禁止脚本执行（FR-PREVIEW-001）。
