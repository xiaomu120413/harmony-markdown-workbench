# 编辑器文件操作与设置 ST-QUALITY-004

REQ-QUALITY-004：编辑当前应用内文档时可确认直接删除，取消不改变内容；删除成功后回到首页，不被自动保存或恢复草稿重新生成。外部文件仍由系统文件管理器删除。置顶与最近共用列表，不再提供独立置顶 Tab。设置页统一分组、间距与控件；修改默认视图后返回当前文档立即应用，未修改偏好时保留临时视图，窄窗口继续遵守分屏宽度限制。

设计：沿用 EditorDocuments、EditorLifecycle 和 SettingsPage，不增加业务抽象。当前文件删除前等待已有检查点完成，保存进行中保留原文件并提示稍后重试；删除成功立即结束编辑器会话，再清理草稿及最近记录。异步保存恢复后须重新检查文件操作门控。默认视图比较已加载偏好与新偏好，只有改变时切换并同步预览。置顶仍按既有排序排在最近顶部。

验证计划：宿主测试覆盖当前删除/取消/保存忙碌/失败/确认期间切换/草稿与元数据失败，覆盖偏好更改及未更改时视图保持；HAP 构建、手机模拟器和可用 PC 的设置布局、预览切换、置顶与删除测试文件。仅使用任务新建文档，不卸载或清数据。UTF-8、文档链接、500 行与 diff 检查后提交推送。

回退：整体回退本提交；不改变文档格式、权限、签名或已有偏好字段。
