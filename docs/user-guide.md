# 木笺 MuMark 使用说明

木笺是 Mu 系列的离线 Markdown 编辑器，支持编辑、预览和分屏。
文档使用标准 Markdown；无需账号，不上传正文、路径或图片。

## 文档位置

- “我的文档”位于应用私有目录。卸载或清除应用数据会删除文档、附件和恢复草稿，请先导出。
- “打开文档”编辑系统选择器授权的原文件，保存写回原位置。
- 在首页从文件管理器拖入一份 `.md`、`.markdown`、`.txt` 或 HTML，会导入副本到“我的文档”。文本可继续编辑，HTML 只读预览；编辑器拖入 TXT、HTML 或图片则插入当前文档的内容节点。不要把应用缓存目录当作长期文件位置。
- 系统文件管理器可通过“打开方式”将支持的文本文件交给木笺。系统必须授予文件访问权，应用不会绕过授权。
- 打开或另存外部文档时尝试保留该文件的访问授权，重启后读取前恢复授权；权限未获批、系统或提供方不支持时使用临时授权。文件被移动、删除或授权撤销后，请重新选择原文件；已有恢复草稿可在首页找回。
- 编辑页“文档 → 查看保存位置”（窄屏为右上角“…”→ 保存位置）区分内部文档、外部原文件和未保存的新文档。

## 打开、拖入与最近列表

首页在 PC 上使用左侧导航与宽文档列表；手机将新建放在标题右侧，底部提供文档、新建和设置入口。首页、编辑器及设置共用纸色背景、蓝绿色强调和浅深主题；编辑器将视图切换与格式工具分组显示。

宽屏通过文件夹图标旁的“文档”打开菜单，可新建、打开或另存，导出副本和复制内容在二级选项中。小于 600vp 的窄屏使用右上角“…”和底部操作面板，展示文档名、保存位置及状态；列表可滚动，二级选项可返回，打开系统选择器前先关闭面板。

窄屏标题栏保留保存，第二行提供编辑/预览、大纲和查找。标题等级、行内格式、列表与缩进、插入操作分别收在“标题 / 格式 / 段落 / 插入”中；撤销和重做直接保留，Ctrl+B、Ctrl+I 等快捷键仍可用。

拖入时会出现原生接收提示。一次接收一份 UTF-8 文本文档或 PNG/JPEG/GIF/WebP/BMP 图片，读取超时会尝试取消系统传输；不支持的格式、缺少授权或失败都会保留当前正文。文本切换存在未保存修改时，需选择保留草稿并打开，或取消切换。

编辑器中拖入图片会复制为应用附件并插入光标处；首页或独立 HTML 预览页拖入图片会新建带图片的 Markdown 文档。单张图片限 20 MB，外部原文件不会修改。

系统复制图片后，可在编辑器中用 Ctrl+V 或系统粘贴操作插入图片；选中正文时会替换该选区。一次一张，格式和 20 MB 上限与拖入图片相同。图片保存为应用附件，支持预览、撤销/重做及图文导出，不额外申请剪贴板读取权限。若系统未交付图片数据，可改用拖入或“插入 → 本地图片”；图片读取期间正文发生变化，会提示重新粘贴，避免插错位置。

Markdown（.md/.markdown）拖入后仍单独打开，不作为节点插入。PDF、Word、Excel 当前不支持拖入；失败会保留当前正文。

编辑器中拖入 TXT，会在当前光标处插入 TXT 内容节点，保留正文和当前文档。预览显示文件的纯文本，不执行脚本，也不解释其中的 HTML 或 Markdown。TXT 附件限 20 MB，支持 UTF-8 和空文件；导出 HTML 可直接阅读，ZIP 包含 TXT 原附件。正文用 `![TXT]` 引用 `attachments/文件.txt`，这是木笺扩展，其他 Markdown 阅读器可能显示图片引用。首页拖入 TXT 或使用“打开文档”仍是打开独立文档。

相同名称和正文的导入副本会复用已有内置文档；同名不同内容使用 `(2)` 等后缀。文档相对图片不会自动从兄弟目录一起导入，请通过“插入 → 本地图片”重新添加，或保留原附件布局使用其他支持目录授权的工具。

最近列表按文件身份去重，不按名称合并不同目录的文件。“我的文档 · 应用内”与“外部 · 位置”区分同名来源；外部 URI 的编码或临时查询别名合并时保留最新地址和置顶标记。

点击文档右侧图钉可置顶或取消置顶。垃圾桶按钮用于删除应用内文件，确认后直接删除，无法恢复；取消不会修改文件。外部原文件请在文件管理器中删除。编辑器侧栏保留在左侧，置顶文档排在最近列表前面，不再单设置顶 Tab。当前文档也可从侧栏或“文档操作”确认删除，成功后返回首页，文件和未保存修改均不保留。正在保存时请稍后再删除。
Office、PDF、HTML、ZIP 和目录不能作为 Markdown 正文导入，会提示使用对应应用。

## 行号旁的折叠按钮

行号旁的小箭头用于折叠或展开内容。标题旁的箭头可收起该章节，其他箭头对应编辑器识别出的多行内容块。点击后暂时隐藏内容，再点可展开；折叠只影响编辑视图，不会删除正文或改写文件，也不改变预览与导出内容。

## 保存与恢复

- 默认自动保存：停止输入约 1.5 秒后写入文件；手动保存可使用 Ctrl+S。
- 关闭自动保存仅停止自动写原文件，恢复草稿继续保留。
- 编辑通知按约 500ms 批处理，请求独立恢复快照；进入后台也尝试刷新。状态栏显示草稿是否写入成功。
- “恢复草稿已保留”仅指应用内恢复副本；“已保存”指当前内容已写入目标文件。
- 保存失败或冲突时不自动覆盖，不把失败当成成功。返回时可保存并离开、保留草稿离开或取消。
- 异常退出后，从首页“找回未保存内容”检查草稿，再恢复或另存副本。
- 尚未传到原生层或尚未落盘的输入，瞬间强杀/断电时仍可能丢失，不承诺逐键零损失。

## 另存与交付

| 文件菜单动作 | 保存目标 | 用途 |
|---|---|---|
| 另存为 Markdown | 成功后切换 | 后续保存修改新文件 |
| 导出 Markdown 副本 | 不切换 | 仅输出当前 Markdown 正文 |
| 导出图文 ZIP | 不切换 | 带走正文和引用的应用附件 |
| 导出 HTML | 不切换 | 本地图片内嵌，适合浏览器查看 |
| 复制内容 | 不切换 | Markdown 原文或渲染 HTML 文本 |

输出使用操作时的正文快照；准备和选择目标期间编辑暂时锁定，完成或取消后恢复。
取消和失败不切换当前目标。目标已存在时先备份内容以供失败恢复；仍受文件提供方和剩余空间限制。
导出失败保留编辑器正文和恢复草稿，不显示成功。

### 图片与 ZIP

本地图片复制到应用附件目录。ZIP 内为 `document.md` 和 `attachments/`，解压后保持该目录结构再打开正文。
单文件 Markdown 不携带图片，输出前会提示；需要完整图文请选择 ZIP。
HTML 内嵌应用图片，不依赖私有路径；网络图片仍保留链接，可能需要联网。

只打包文档引用的应用附件，不扫描未授权目录。外部文档的兄弟目录图片应先用图片选择器重新插入。
缺失、非法路径或超限会阻止不完整交付。
支持 PNG/JPEG/GIF/WebP；单张 20 MiB，ZIP 附件合计 100 MiB，HTML 附件合计 20 MiB。
目标已有文件的备份上限为 32 MiB，超过时请选择新文件名。

## 边界

不包含云同步、AI、PDF、目录工作区或向具体收件人发送文件。
原始 HTML 在 Markdown 预览中禁用，标签按安全规则处理。
真机和未验证项见[本轮记录](spec/productization-verification.md)。

## 设置与帮助

首页或编辑器的“设置”可调整主题、字号和保存选项；“草稿与帮助”中可展开使用帮助与外接键盘快捷键。修改“默认视图”后，返回当前文档立即应用；未修改该偏好时保留临时切换的视图。分屏需要足够宽度，手机窄窗口会显示为编辑。

主题可选“跟随系统、浅色、深色”。新配置默认跟随系统，原来手动选择的浅色或深色会保留；切换主题实时更新编辑与预览，不重新载入正文。

手机横屏跟随系统旋转锁定设置。横屏未弹键盘时保留编辑、预览和格式工具栏，可横向滑动查看末尾操作；弹键盘时收起工具栏，收键盘后恢复。查找面板在低矮窗口中可纵向滚动，给命中正文保留空间。

PC 使用 Tab / Shift+Tab 遍历按钮、最近文档、资料库与大纲，Enter / Space 激活；正文内 Ctrl+F 打开查找并聚焦查找框，Escape 关闭查找并返回正文，Shift+F10 打开系统上下文菜单。系统分屏先选择配对窗口，再拖动两窗口之间的比例条；可调范围同时受另一应用的最小宽度限制。

## 插入 HTML 内容块

在编辑器中拖入 `.html` / `.htm`，或选择“插入 → HTML 内容块…”，会像插入图片一样在当前光标处加入引用；预览和分屏显示 HTML 效果。当前文档不跳页。图片、CSS、CSS @import 和背景图先合成为离线 HTML 附件；缺少授权时，支持目录选择的平板及 2in1 可选择 HTML 所在目录，手机直接选择所需图片/CSS 文件，必要时分次补齐。取消不会改正文。

Markdown 使用图片式 `![HTML]` 引用，路径为 attachments 下的 HTML 附件，这是木笺的内嵌扩展；其他 Markdown 阅读器可能只显示图片引用。附件随图文 ZIP 导出；网页 HTML 导出也内嵌内容块。单独 Markdown 文件仅包含正文和引用，不能携带附件。插入后不再依赖原目录，也不保留该目录的长期授权。

内容块为只读、固定高度并可在块内滚动。脚本、事件、联网、外部跳转及嵌套页面禁用。原始 HTML 限 8 MiB；单资源 4 MiB，共 128 个 / 32 MiB；合成附件限 12 MiB。暂不支持带 layer()/supports() 的 CSS @import 条件及动态脚本内容。

## 单独打开 HTML

通过“打开文档”选择 `.html` / `.htm`，或在首页拖入 HTML，可单独只读预览排版、表格、内联样式和内嵌图片。返回后可继续编辑原 Markdown 文档。HTML 不进入自动保存。

预览禁用脚本、联网、跳转和同目录文件读取，外链图片及需要 JavaScript 的交互不会加载。目前支持 UTF-8 HTML，内容限 8 MB。
